Connect your local agent.

Run Tora on your computer, then pair this extension using the key in .local-token at the project root.

  1. Run python scripts/setup.py in your Tora folder.
  2. Open .local-token in a text editor and copy its contents.
  3. Paste the key below. It stays in this extension's local storage.
